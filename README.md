# CrowFeather · 鸦羽人

**你只是路过并做出选择。**

头顶响起鸦叫声，路灯为谁点亮？雾气愈发浓厚，丧钟为谁而鸣？

2D 像素风、2.5D 正视角探索与叙事游戏，使用 **Godot 4.6.3**。项目位于 `godot-game/crow-feather`，入口 `scenes/PixelMain.tscn`，支持 Android ARM64、Windows x64、Linux x64。

当前原型包含可行走墓园与三份持久化存档、五类角色及遗体调查、五套区域雾色、抹去与保留的因果分支、背包、键盘与触控、舒适性 / 音量 / 显示设置，以及不写入正式存档的 DEV 测试房。DeepSeek 接口默认关闭，剧情可以完全离线运行。
